# Umuarama Gestão Operacional

Sistema de gestão operacional do Umuarama by Castelo (Recepção, Governança, A&B, Manutenção e Gerencial).

- Site: https://tcrz5sd64v-source.github.io/umuarama-gestao/
- Banco de dados: Cloud Firestore (configuração em `firebase-config.js`, regras em `firestore.rules`).
- Os dados iniciais (`dados-iniciais.json`) são carregados no banco automaticamente no primeiro acesso.
